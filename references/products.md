# 产物与图类型

产物名是功能入口的第二段，例如 `whh 章节 知识地图` 里的「知识地图」。

| 产物 | 生成内容 | 图类型 | 可用范围 |
|---|---|---|---|
| 知识地图 | 知识结构总图 | Tree / Dependency graph / Loop | 全部、章节、节点 |
| 定理体系 | 定理依赖关系 | Dependency graph | 全部、章节、节点 |
| 时间线 | 事件与时期 | Timeline | 全部、章节、节点 |
| 因果链 | 事件因果关系 | Dependency graph（左→右） | 全部、章节、节点 |
| 实验分析 | 实验流程 | Process | 章节、节点 |
| 架构图 | 系统组件关系 | Architecture | 全部、章节、节点 |
| 学习路径 | 知识依赖顺序 | Dependency graph | 全部、章节 |
| 结构图 | 曲式、乐章、章节的嵌套结构 | Nested | 全部、章节、节点 |
| 详解 | 单点知识展开 | 无图，正文 | 节点 |
| 练习 | 基于知识点的题目 | 无图 | 章节、节点 |
| 专业拆解 | 作品的音乐学拆解（作品模式） | 无图，正文 | 全部 |
| 听赏指南 | 分段听点指南（作品模式） | Timeline | 全部、章节 |

## 布局

| 布局 | 用于 | 行为 |
|---|---|---|
| `layered` | 知识地图、定理体系、因果链、架构图、实验分析、学习路径 | 按依赖层级分列，正交连线 |
| `timeline` | 时间线、听赏指南 | 单条时间轴，节点上下交替；按 `attributes.year` / `order` / `time` 排序 |
| `nested` | 结构图 | **尚未实现**，目前回退到 `layered` |

节点超过 `--max-nodes`（默认 9）时：

- 普通布局按关联度截断，并在图注里写明「还有 N 个未显示」。
- 时间线按时间顺序截断，保证留下来的是一段连续的年代。
- 加 `--split` 时改为「章节总览 + 每章一张明细」，不再靠截断。

## 各 Profile 可用产物

| Profile | 可用产物 |
|---|---|
| mathematics | 知识地图、定理体系、学习路径、详解、练习 |
| natural-science | 知识地图、实验分析、学习路径、详解、练习 |
| humanities | 知识地图、时间线、因果链、学习路径、详解 |
| computer | 知识地图、架构图、学习路径、详解、练习 |
| language | 知识地图、学习路径、详解、练习 |
| music-learning | 知识地图、结构图、学习路径、详解、练习 |
| music-appreciation | 专业拆解、听赏指南、知识地图、时间线、结构图、学习路径、详解 |

不适用的组合不出现在选项里。历史教材不该看到「架构图」。

## 图的硬约束

来自 diagram-design 技能，不可违反：

- 单图节点上限 9。超过则拆 overview + detail 两张。
- 单图焦点节点不超过 2。
- 图只承载关系、命名和深度角标，不承载长文本。
- 节点必须来自知识库，不能为填满布局而补实体。
- 无对应图类型的产物就用正文或表格，并在报告里注明「无对应图类型」。

## 全书知识地图不是一张图

一本教材上百个节点，必须按章或知识域分片。`whh 全部 知识地图` 的输出是一组分片图 + 一条主线路径，不是一个巨型 SVG。
