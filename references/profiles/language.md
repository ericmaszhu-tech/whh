# 语言学习 Profile

适用于英语、汉语及第二语言教材。建模目标是语言知识体系、规则、词汇与使用场景。

## 实体

| 实体 | 关键属性 |
|---|---|
| Vocabulary 词汇 | 词形、词性、释义、常见搭配 |
| GrammarRule 语法规则 | 规则表述、适用条件、例外 |
| SentencePattern 句型 | 结构、成分、使用场合 |
| Expression 固定表达 | 形式、含义、语域（正式/口语） |
| Pronunciation 发音 | 音标、重音、连读规则 |
| Semantic 语义 | 义项、褒贬、近义反义 |
| Context 语境 | 场景、对象、得体性 |
| Dialogue 对话 | 参与者、目的、典型句式 |
| Example 例句 | 例句、对应用法 |
| Exercise 练习 | 考点、难度、答案 |
| ErrorPattern 常见错误 | 错误形式、成因、正确说法 |

## 关系

`belongs_to` `modifies` `expresses` `contrasts_with` `used_in` `transforms_into` `applies_to`

- `contrasts_with` 用于近义、易混、对立，必须注明区别点。
- `used_in` 方向固定：语言单位 → 语境。

## 深度

| 深度 | 语言专属要求 |
|---|---|
| L1 | 单元主题、核心词汇表、语法点名称 |
| L2 | 词义与词性、规则表述、典型例句 |
| L3 | 搭配与语域、规则例外、易混辨析、常见错误 |
| L4 | 完整用法网络、多语境对比、学习者偏误分析、进阶路径 |

## 抽取顺序

词汇 → 词义 → 语法规则 → 句型 → 语境 → 例句 → 练习。

先抽词义而不是词形：同一个词形在不同语境下可能是不同实体。

## 校验要点

- 词性与释义必须来自教材，不得自行补充义项。
- 例句与所讲规则对应，不能拿一个规则配无关例句。
- 语域标注（正式/口语/书面）缺失时标 `partial`。
- 近义辨析必须写出区别点，不能只列两个词。

| 视图 | 图类型 |
|---|---|
| 知识地图 | Tree |
| 词汇体系 | Tree |
