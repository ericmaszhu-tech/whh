# 音乐鉴赏 Profile

适用于音乐史、作品分析、作曲家与流派、听赏指南。建模目标是作品与听赏，不是规则训练。

## 实体

| 实体 | 关键属性 |
|---|---|
| Work 作品 | 曲名、作品编号、体裁、调性、时长 |
| Composer 作曲家 | 生平、所属时期、风格特征 |
| Period 时期 | 年代范围、风格特征、代表体裁 |
| Genre 体裁 | 体裁定义、典型结构、典型编制 |
| Movement 乐章 | 序号、速度标记、曲式 |
| Style 流派 | 流派特征、代表作曲家、与前后流派的关系 |
| Form 曲式 | 结构类型、段落划分 |
| Theme 主题 | 主题性格、出现位置、变形方式 |
| MusicalElement 音乐要素 | 旋律、和声、织体、配器、力度 |
| ListeningPoint 听赏要点 | 时间点、听辨对象、预期感受 |
| Performance 演绎 | 版本、指挥、乐团、录音年代 |
| Context 背景 | 历史条件、社会语境、美学观念 |

## 关系

`composed_by` `belongs_to_period` `belongs_to_genre` `contains_movement` `developed_from` `influenced_by` `exemplifies` `analyzed_as` `listened_for` `premiered_in`

`influenced_by` 必须能指出影响的具体方面（配器、和声、结构），不能只写「受影响」。

## 深度

| 深度 | 音乐鉴赏专属要求 |
|---|---|
| L1 | 时期、代表作曲家、代表作品清单 |
| L2 | 作品基本信息、体裁归属、流派归属、主要听赏点 |
| L3 | 曲式段落划分、主题变形、听赏要点的具体时间位置、版本差异 |
| L4 | 逐段结构与和声分析、多版本对比、与其他作品的风格关联、文化语境 |

## 抽取顺序

时期 → 作曲家 → 体裁 → 作品 → 乐章 → 曲式 → 主题 → 听赏要点 → 版本。

先抽时期和作曲家：作品归属错了，后面的流派和影响关系会整片错。

## 校验要点

- 作品与作曲家、时期必须对应，不得出现生卒年与创作年代矛盾的组合。
- 曲式段落与作品结构一致；段落名称要能对应到乐章或小节范围。
- 听赏要点必须带时间位置，不能只有「注意听主题」这类无法定位的描述。
- 版本信息（指挥、乐团、录音年代）缺失时标 `partial`，不猜测。
