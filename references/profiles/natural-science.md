# 自然科学 Profile

适用于物理、化学、生物、地理。建模目标是概念、规律、机制、模型与实验之间的关系。

## 实体

| 实体 | 关键属性 |
|---|---|
| Concept 概念 | 定义、所属分支、与相邻概念的分界 |
| Principle 原理 | 表述、前提、适用范围 |
| Law 定律 | 表述、表达式、成立条件、边界 |
| Theory 理论 | 核心命题、适用范围、证据基础 |
| Model 模型 | 理想化假设、适用条件、失效情形 |
| Formula 公式 | 表达式、符号含义、单位、适用条件 |
| Variable 物理量 | 符号、单位、量纲、测量方式 |
| Mechanism 机制 | 作用环节、参与要素、方向性 |
| Experiment 实验 | 目的、装置、步骤、控制变量 |
| Observation 观测 | 现象描述、测量值、误差范围 |
| Result 结果 | 数据、结论、与理论的对应 |
| Condition 条件 | 成立条件、近似程度 |
| Application 应用 | 场景、依赖条件 |

## 关系

`explains` `causes` `depends_on` `affects` `measures` `observes` `demonstrates` `validates` `applies_to`

- `validates` 方向固定：实验结果 → 理论或定律。
- `measures` 方向固定：测量手段 → 被测量的量。

## 深度

| 深度 | 自然科学专属要求 |
|---|---|
| L1 | 分支主题、核心概念名、主要定律名 |
| L2 | 概念定义、定律表述、主要公式、典型实验 |
| L3 | 公式适用条件、机制环节、实验变量与误差、模型假设 |
| L4 | 完整推导、实验设计与误差分析、模型失效边界、跨章机制关联 |

## 抽取顺序

概念 → 物理量 → 定律 → 公式 → 条件 → 实验 → 应用。

先抽物理量：单位和量纲不先定死，后面的公式会出现符号冲突而无法判断。

## 校验要点

- 物理量必须带单位；同一符号在全书中含义是否变化。
- 公式必须带适用条件，无条件公式不得标 `complete`。
- 实验必须有控制变量与观测量的区分。
- 理论与实验的对应关系要能指出具体数据或现象。
