# 人文与社会科学 Profile

适用于历史、政治、哲学、社会学、经济学教材与论著。建模目标是概念体系、论证结构与因果解释。

## 实体

| 实体 | 关键属性 |
|---|---|
| Concept 概念 | 定义、内涵、与相邻概念的分界 |
| Argument 论点 | 主张、前提、结论、所属章节 |
| Evidence 论据 | 类型（史实/数据/引文/事例）、支持哪个论点 |
| Theory 理论 | 核心命题、适用范围、提出者 |
| Thinker 人物 | 身份、立场、代表观点 |
| Event 事件 | 时间、地点、参与方、结果 |
| Period 时期 | 起止、主要特征 |
| Institution 制度 | 内容、设立背景、演变 |
| Cause 原因 | 层次（根本/直接）、作用对象 |
| Consequence 结果 | 短期/长期、影响范围 |
| Perspective 观点 | 立场、与主流看法的差异 |
| Case 案例 | 场景、用来说明什么 |

## 关系

`causes` `results_in` `influences` `precedes` `belongs_to` `supports` `contradicts` `represents` `evolves_from` `presupposes` `exemplifies`

- `supports` 方向固定：论据 → 论点，不反向记录。
- `contradicts` 必须能指出对立的具体主张，不能只写「观点不同」。
- `presupposes` 用于「要成立必须先成立」的隐性前提，比 `causes` 弱。

## 深度

| 深度 | 人文社科专属要求 |
|---|---|
| L1 | 章节主题、核心概念名、主要论点一句话 |
| L2 | 概念定义、论点主张、主要论据、基本因果 |
| L3 | 论证链条、论据与论点的对应、不同观点的分歧点、因果层次 |
| L4 | 完整论证结构还原、反例与反驳、概念的演变、跨章的理论关联 |

## 抽取顺序

概念 → 论点 → 论据 → 因果 → 人物与时期 → 观点分歧。

先抽概念：人文文本里的争论多数是同一个词的不同定义，概念不先定死，后面的论点会互相打架。

## 校验要点

- 论点与论据必须配对：每个 `supports` 都要能说清「支持了哪一句主张」。
- 因果不能倒置，也不能把相关当因果。
- 时期与事件的时间不得矛盾。
- 引文必须能在原文中找到，转述要标 `ai-inference`。
