# 音乐学习 Profile

适用于乐理、视唱练耳、和声、曲式、器乐与声乐教程。建模目标是规则与技能，不是作品。

## 实体

| 实体 | 关键属性 |
|---|---|
| Concept 概念 | 定义、所属范畴、与相邻概念的分界 |
| Notation 记谱符号 | 符号形态、读法、书写规则、所在谱表 |
| Interval 音程 | 度数、音数、协和性、转位 |
| Scale 音阶 | 调式结构、主音、音级名称 |
| Chord 和弦 | 构成音、转位、功能属性 |
| Key 调性 | 调名、关系调、调号、同主音调 |
| Rhythm 节奏 | 拍号、时值组合、强弱规律 |
| Rule 规则 | 规则内容、适用条件、例外 |
| Technique 技能要点 | 动作要领、常见偏差、纠正方法 |
| Exercise 练习 | 训练目标、难度、对应技能 |
| Repertoire 曲目 | 曲名、作曲家、技术难点、适用阶段 |
| ErrorPattern 常见错误 | 错误表现、成因、纠正步骤 |

## 关系

`belongs_to` `precedes` `requires` `derived_from` `resolves_to` `transposes_to` `applied_in` `contrasts_with` `notated_as`

`resolves_to` 用于和声解决，方向固定：不稳定音级 → 稳定音级，不反向记录。

## 深度

| 深度 | 音乐学习专属要求 |
|---|---|
| L1 | 章节主题、核心乐理概念名、技能模块 |
| L2 | 概念与符号定义、音程与和弦构成、基本规则、练习目标 |
| L3 | 规则的适用条件与例外、和声进行、技能要点偏差、练习与技能映射 |
| L4 | 完整和声进行链、多种配和方案、曲目逐句技术标注、进阶路径 |

## 抽取顺序

符号 → 概念 → 音程 → 音阶 → 和弦 → 规则 → 技能要点 → 练习 → 曲目。

先抽符号与概念：后面的音程、和弦、规则都建立在同一套记号上，跳过会导致记号含义漂移。

## 校验要点

- 调号与音阶、和弦一致：同一调号下不得出现矛盾音级。
- 和声进行合法性：功能性进行要能指出依据，不能凭感觉标。
- 书写规范：五线谱与简谱记号不得混用在同一实体属性里。
- 乐谱无法解析时保留图片索引，不得转写成文本音符冒充原文。
