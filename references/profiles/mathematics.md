# 数学 Profile

首个可用切片。其他学科按同一结构扩展，不改引擎。

## 实体

| 实体 | 关键属性 |
|---|---|
| Concept 概念 | 定义、性质、记号 |
| Definition 定义 | 定义内容、适用范围、易混概念 |
| Theorem 定理 | 条件、结论、适用前提、逆命题是否成立 |
| Proposition 命题 | 表述、真值条件 |
| Formula 公式 | 表达式、变量含义、成立条件 |
| Proof 证明 | 前提、推理步骤、结论、所用定理 |
| Derivation 推导 | 起点、步骤、结果、关键变形 |
| Method 方法 | 适用题型、步骤、约束 |
| Example 例题 | 题干、条件、目标、解法、答案 |
| Counterexample 反例 | 针对的命题、构造方式 |
| Misconception 易错点 | 错误表现、成因、纠正方式 |

## 关系

`prerequisite_of` `defines` `implies` `proves` `derives_from` `equivalent_to` `generalizes` `specializes` `applies_to` `contradicts`

关系方向必须一致：`prerequisite_of` 从先行知识指向后继知识，不反向重复。

## 深度

| 深度 | 数学专属要求 |
|---|---|
| L1 | 章节主题、核心概念名、章节间基本顺序 |
| L2 | 概念与定义、定理表述、主要公式、典型方法、基本依赖 |
| L3 | 定理条件与边界、证明链条、公式适用范围、方法适用题型、易错点、反例 |
| L4 | 完整推导步骤、多种解法、例题与知识点逐项映射、练习考查目标、跨章演进 |

## 抽取顺序

定义 → 概念 → 性质 → 定理 → 证明 → 推导 → 例题 → 练习。

同一 Content Unit 里按此顺序抽取，先抽定义能显著减少后续定理条件的歧义。

## 校验要点

- 公式变量一致性：同一符号在全书中含义不变，变了要作为新实体并注明适用范围。
- 定理前提完整性：条件缺失的定理不得标 `complete`。
- 推导逻辑一致性：跳步要标 `partial`，不能补全后当作教材原文。
- 定理与证明对应：`proves` 两端必须同时存在，否则关系作废。
